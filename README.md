# Impostor Word Game

A lightweight browser game for **3 to 10 players**:

- One random player is the impostor.
- Everyone else gets the same secret word.
- The impostor must blend in during discussion.
- The round has a built-in **5-minute timer**.
- If the impostor is selected to speak first, they receive a better hint.

## Run

Open `index.html` in a browser.
